# Coding Practice

A collection of beginner-friendly Python exercises covering core programming concepts.

## Exercises

| File | Topics |
| --- | --- |
| [`Basic Operations Exercise.py`](<./Basic Operations Exercise.py>) | Practice object creation, list repetition and concatenation, and counting items. |
| [`Basic Operators.py`](<./Basic Operators.py>) | Examples of arithmetic, modulo, exponentiation, string operations, and list operations. |
| [`Basic Strings.py`](<./Basic Strings.py>) | Explore string formatting, searching, slicing, and common string methods. |
| [`Conditions.py`](<./Conditions.py>) | Practice comparisons, Boolean operators, membership, identity, and conditional statements. |
| [`exercise 1.py`](<./exercise 1.py>) | Practice with variables, strings, floats, integers, and basic type checks. |
| [`exercise 2 lists.py`](<./exercise 2 lists.py>) | Create lists, append values, access items by index, and iterate over a list. |
| [`lists exercise.py`](<./lists exercise.py>) | Practice adding numbers and strings to lists and retrieving a name by index. |
| [`Strings.py`](<./Strings.py>) | Practice string length, indexing, slicing, case conversion, prefix checks, and splitting. |

## Run an exercise

Run a script from this folder with Python 3:

```powershell
python "exercise 1.py"
```

## Regenerate this README

To update it once after adding or removing Python exercise files, run:

```powershell
python generate_readme.py
```

To keep it updated automatically while you add, remove, or rename Python files, run:

```powershell
python generate_readme.py --watch
```

Leave that command running in a terminal. It checks for file changes every two seconds; press Ctrl+C to stop it.
